# Machine Learning Assignment – Clustering & SVM

This repository contains the implementation of **Clustering algorithms** on the **Carseats dataset** and **Support Vector Machines (SVM)** on the **MNIST dataset**.  
The goal is to explore unsupervised learning (clustering) and supervised learning (classification) techniques, compare their performance, and visualize the results.

---

## 📂 Contents
- **Question 1: Clustering (Carseats Dataset)**
  - K-Means Clustering
  - K-Medoids Clustering
  - K-Median Clustering
  - Hierarchical Clustering (Agglomerative & Divisive)
    - Inter-cluster similarity: Min, Max, Average
    - Dendrogram & Venn Diagram
  - Cluster visualization with scatter plots
  - Comparative analysis of clustering methods

- **Question 2: Support Vector Machine (MNIST Dataset)**
  - Linear SVM (One-vs-All strategy)
  - Standardized Linear SVM
  - Non-linear SVM with RBF Kernel
  - Training & Testing Accuracy comparison
  - Prediction analysis and comparative study

---

## 📊 Datasets
- **Carseats Dataset**  
  Used for clustering algorithms. Contains attributes like competitor price, income, advertising, population, price, age, and education.

- **MNIST Dataset**  
  Handwritten digits dataset with **70,000 images (28×28 pixels each)**.  
  Download from [Kaggle](https://www.kaggle.com/datasets/hojjatk/mnist-dataset).
